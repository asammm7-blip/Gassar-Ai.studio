
## 2026-11-07 — 08-multimodal-server: Vision وmmproj والخادم المحلي
أضيف ربط ملف `mmproj` الفعلي من شاشة النماذج مع نموذج GGUF، وتهيئة `llama.rn.initMultimodal` عند تحميل النموذج، وتمرير `image_url` و`media_paths` عبر مسار OpenAI المحلي. يقبل الخادم صور Base64 ويكتبها مؤقتاً داخل تخزين التطبيق، ويرفض جلب الصور من الإنترنت أو إرسالها إلى نموذج بلا Projector Vision. أضيف دعم `input_audio` فقط عندما يعلن السياق الأصلي دعم الصوت، وتمرير tool schemas وإرجاع tool calls التي ينتجها llama.rn دون تنفيذ أوامر نظام غير مصرح بها. وسّع استخراج النصوص ليشمل JSON وRTF وXML، ورفعت حد جسم الطلب الافتراضي إلى 16MiB (والحد الأعلى 32MiB) لحجم الصور.
أضيفت بطاقة تقدم ملونة تعتمد على حالة LocalModelManager الحقيقية، وزر ربط/تغيير `mmproj` مع تنبيهات عربية واضحة. أضيفت اختبارات HTTP لقبول صورة Base64 ورفض رابط صورة خارجي.
الدليل: TypeScript ناجح، 155 اختباراً ناجحاً واختبار مصادقة قديم متخطى، وLint ناجح بلا أخطاء أو تحذيرات بعد هذه الدفعة. يبقى اختبار llama.cpp/Projector الفعلي على جهاز Android مطلوباً لأنه يحتاج ملفات النماذج والجهاز نفسه.
