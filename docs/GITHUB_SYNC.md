# مزامنة Gassar.AI مع GitHub

المستودع المعتمد الوحيد هو `https://github.com/asammm7-blip/manus-gassar.Ai.git` والفرع `main`. المزامنة تحفظ **مصدر التطبيق**، وليست نسخًا احتياطيًا لمحادثات المستخدم أو قاعدة البيانات. تبدأ بعد حفظ خطوة كاملة في التزام Git، ولا تراقب كل تعديل أو تنشئ مهمة دورية.

## التفعيل والحفاظ على الإعدادات

```sh
cd /home/ubuntu/gassar-ai
pnpm github:sync:enable
```

يلزم Python 3.12+ ونسخة pnpm المقفلة في `package.json`، وGitHub CLI المصادق عليه للمستودع المصرح فقط. لا تطلب الأداة تسجيل دخول تفاعليًا ولا تخزن tokens. يفحص المثبت جميع fetch/push URLs **بعد** توسعات Git؛ لا يضيف أو يبدل remote، ويحافظ على `origin` وعلى Git العام. يرفض أي hooksPath مختلف، بما فيه الموروث من الإعدادات العامة، أو hooks فعلية في الدليل التقليدي قد يحجبها التفعيل. يكتب `.githooks` في إعداد النسخة المحلي فقط.

عند إعداد نسخة جديدة يدويًا، يجب أن يكون remote `github` موجودًا بعنوان واحد مطابق تمامًا للوجهة أعلاه. عنوانان ولو كانا متماثلين ليسا «عنوانًا واحدًا» ويُرفضان. لا يغيّر المثبت الاعتمادات أو صلاحيات الحساب.

## ضمان المصدر والوجهة

`github-sync.py` يثبت SHA عند بدء العملية، ويتطلب `main` وشجرة عمل مكتملة، بما فيها الملفات غير المتتبعة وغير المستثناة. يفحص كل ملفات الشجرة ثم أرشيف Git لذلك SHA، **لا ملفات ROOT الحية**. يرفض الملفات الحساسة أو المولدة والمرفقات الكبيرة والروابط الرمزية وsubmodules لكي لا تعتمد اللقطة على ملف خارجي متغير.

تُفك اللقطة في دليل مؤقت تحت `.git` بدون مستودع أو hooks. ملفات المصدر للقراءة فقط، وتُقارن بصمات SHA-256 قبل الفحوص وبعد كل أمر. تُثبّت اعتمادات JS في اللقطة نفسها بأمر `pnpm install --offline --frozen-lockfile --ignore-scripts`؛ لا يُستخدم رابط إلى `node_modules` الحي، ولا تُحل إصدارات أحدث أو تُنفّذ lifecycle أصلية/تنزيل أصول محرك خلال بوابة JS. غياب الحزم من cache أو اختلاف إصدار pnpm أو lockfile يُفشل العملية بأمان. توفير cache المقفل خطوة مشغل منفصلة؛ لا يعني تجاهل lifecycle أن APK أصليًا صالحًا، فمرحلة الإصدار الأصلي تتحقق منها بشكل مستقل.

تعمل الأوامر الأربعة `pnpm check` و`pnpm test` و`pnpm test:sync` و`pnpm lint` في اللقطة. بيئتها محدودة ولا تمرر مفاتيح المزودين أو متغيرات إعداد Git المحقونة. يُحجب خرج الأدوات الخام عن سجل المزامنة لأنه قد يتضمن أسرارًا أو نصوص المستخدم؛ شغّل الأمر الفاشل مباشرةً محليًا للتشخيص بعد مراجعة سرية بيئته. ليس هناك `--skip-checks` ولا تجاوز `GASSAR_SKIP_SYNC`. اختبار Python يستخدم مستودعات مؤقتة ونقلًا محليًا بديلًا؛ لا يستدعي hook بشكل متكرر ولا يدفع fixture إلى GitHub.

قبل **كل نقل** تُراجع كل عناوين `github` وتوسعات العنوان الصريح، بما فيها `insteadOf` و`pushInsteadOf`. يُنفذ fetch/push/ls-remote إلى URL ثابت متحقق منه، وليس اسم remote متعدد الوجهات. تُحظر إعادة توجيه HTTP ويُعطل hook في أمر النقل فقط، دون تعديل إعداد المشروع. يدفع Git SHA المحدد إلى `refs/heads/main` بلا force. إذا تقدّم البعيد أو تفرّع، يتوقف حتى دمج صريح يحافظ على عمل المستخدم. يفحص جميع blobs الخارجة، بما فيها ملفات محذوفة في التاريخ، ورسائل وmetadata الالتزامات بحثًا عن أنماط أسرار معروفة. **الفحص احترازي محدود الأنماط، لا ضمان كشف جميع الأسرار.** إذا اكتُشف سر حقيقي يلزم معالجة تاريخه وتدويره؛ حذف الملف الحالي فقط لا يكفي.

تغير HEAD أو ملفات العمل أثناء الفحوص يمنع النقل. المصدر المختبر نفسه مستقل عن المحرر. بعد الدفع تُقرأ `refs/heads/main` من الوجهة المتحققة وتُقارن بالـSHA، ثم تُراجع حالة المصدر مجددًا قبل إعلان success. لا تدعي الأداة نجاح نسخة أحدث إذا تغيرت أثناء النقل.

## حالة محلية محررة

تكتب العملية ذريًا `.git/gassar-sync-status.json` بصلاحية `0600`، وتزيل ملف النجاح القديم `.git/gassar-sync-status.txt` حتى لا يظهر آخر نجاح بعد فشل جديد. الحقول: `schemaVersion` و`state` و`timestamp` بتوقيت UTC و`sha` و`mode` و`target` و`branch` و`checks` و`errorCode` و`remoteSha`. لا تُسجل ملفات المستخدم أو محتويات الطلبات أو الأسرار أو stderr الخام.

الحالات `running` و`success` و`failure` خاصة بتنفيذ المزامنة. `validated-local` للفحص المحلي وحده و`validated-not-pushed` للتجربة الجافة، ولا تعنيان نشرًا أو نسخة إصدار معتمدة. القفل يمنع عمليتين متزامنتين؛ استدعاء مشغول لا يستبدل حالة مالك القفل. الحالة داخل `.git` غير مرفوعة وليست شاشة تطبيق بعد.

```sh
cd /home/ubuntu/gassar-ai
pnpm github:sync:dry-run  # فحوص لقطة وتاريخ، لا push
pnpm github:sync          # إعادة محاولة صريحة، الفحوص كاملة من جديد
pnpm test:sync            # اختبارات محلية بلا اعتماد شبكة حية
```

فشل hook لا يحذف الالتزام المحلي. عند خطأ عابر يُعاد `pnpm github:sync` مرة، ولا توجد إعادة محاولة دائمة. لا تُرفع خطوة نصف مكتملة أو تُحل تعارضات بالـforce.

## CI وحدود اعتماد الإصدار

`.github/workflows/source-validation.yml` يشغّل check/test/test:sync/lint على commit في push إلى main أو pull request بصلاحية `contents: read` فقط، وبدون اعتماد checkout محفوظ أو أسرار أو نشر إنتاجي. Node/pnpm مثبتان، والتثبيت frozen بدون lifecycle أصلي، وآخر خطوة ترفض تغير ملفات المصدر. وجود workflow في المصدر لا يعني أن GitHub Actions شغّله أو أن حماية الفرع مفعلة؛ يجب التحقق من النتيجة البعيدة بشكل مستقل.

هذه بوابة **مصدر JS**. لا تثبت APK/AAB أو Kotlin/JSI أو توقيعًا أو هاتفًا. المنتج المقصود Expo SDK 57 ببناء أصلي، لا Expo Go. الخادم ووحدة Android وGGUF تحتاج بناءً أصليًا والتحقق على artifact والجهاز. راجع `docs/IMPLEMENTATION_STATUS.json` و`docs/DELIVERY_STATUS.md` للحدود الدقيقة؛ لا تغيّر هذه المرحلة وظائف الحساب أو السحابة أو الصوت أو النماذج.
