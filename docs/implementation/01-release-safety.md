# 01 — تأمين المزامنة وسجل التنفيذ

**النطاق:** المرحلة `01-release-safety` فقط. خط الأساس `c21b19d39881395209af12ef526a825cf4ef800c`. الأدلة التدقيقية الأصلية محفوظة دون تعديل. لا تغييرات تطبيقية في الحسابات أو الدردشة أو محرك GGUF أو الصوت أو SDK 57.

## التنفيذ الفعلي

أُعيد تنفيذ `scripts/github-sync.py` لإغلاق BE-09 وBE-10 في المصدر. تُراجع **كل** عناوين fetch/push الموسعة ويُرفض أكثر من عنوان واحد ولو متماثلًا. فحص مستقل للعنوان الصريح يكشف `pushInsteadOf` حتى إذا كان pushurl البعيد يعطل التوسع عند فحص اسم remote. يستخدم نقل fetch/push/ls-remote العنوان المتحقق الثابت، لا remote مجموعة وجهات، مع منع HTTP redirects وعدم force أو تعديل origin/Git العام.

يثبت التنفيذ SHA ويُفحص أرشيفه المعزول تحت `.git`؛ ملفات المصدر للقراءة فقط وتُربط بصماتها ببايتات Git blobs، فلا تسمح export-ignore/export-subst باختبار شجرة مختلفة. يُثبت رسم اعتمادات منفصل مقفل offline/frozen بدون lifecycle أو رابط إلى الاعتمادات الحية. كل فحص يتبعه تحقق البصمات، مع مراجعة HEAD ونظافة الملفات قبل النقل وبعده. لا مستودع/hooks في اللقطة، ونقل Git يعطل hooks في الأمر نفسه فقط. غياب cache المقفل يفشل مغلقًا. هذه سياسة فحص JS، لا دليل تنزيل أصول native أو APK.

أزيل `--skip-checks` وأزيل تجاوز `GASSAR_SKIP_SYNC` من hook والتوثيق. رفض معامل غير مدعوم يسجل failure محليًا بدل إبقاء نجاح قديم. الحالة JSON ذرية بصلاحية 0600، وتتضمن running/success/failure وSHA وتوقيت UTC والأوامر المجتازة ورمز خطأ محرر. الفحص المحلي والتجربة الجافة حالتان منفصلتان لا تدعيان نجاح نشر. تُحجب المخرجات الخام ومفاتيح المزودين من بيئة الفحوص. الرسائل تُظهر رموزًا ثابتة دون اسم ملف حساس أو سر أو محتوى طلب. يرفض القفل تشغيلًا متزامنًا ولا يستبدل حالة العملية المالكة.

يفحص التنفيذ الشجرة والتاريخ الخارج، بما فيه blobs محذوفة ومسارات تاريخية وروابط ورسائل/metadata الالتزامات. يحتفظ الفاحص بحده الصريح: أنماط اعتماد معروفة و20MiB لكل blob، **لا ضمان شامل للكشف**. التعارض البعيد يتوقف لدمج صريح؛ فشل النقل يبقي الالتزام المحلي ويستلزم إعادة محاولة كاملة الفحوص.

المثبت `scripts/install-github-sync.mjs` يستعمل validator الإنتاجي نفسه، ويحافظ على hooksPath الموروث والمحلي وhooks الدليل التقليدي ويرفض حجبها. أضيف workflow `source-validation.yml` بصلاحية contents:read فقط، بلا اعتماد checkout محفوظ أو أسرار أو نشر. يقوم check/test/test:sync/lint وتثبيت frozen ورفض تعديل المصدر على commit. إضافته مصدرًا **ليست إثبات تشغيل GitHub Actions أو حماية الفرع**.

أُنشئ `docs/IMPLEMENTATION_STATUS.json` بكل **79 معرف تدقيق** وعشر إضافات أصلية. BE-09 وBE-10 implemented-source-tested؛ BE-11 جزئي فقط لاختبارات المزامنة وCI المصدرية. 76 نتيجة pending، وعشر إضافات pending. الإضافة العاشرة تسجل أساس الحالة المحلي فقط؛ لا لوحة تطبيق أو طاقة أو artifact مصطنع. `containing-commit` يربط الدليل بالالتزام الحامل دون SHA ذاتي مستحيل؛ المرحلة التالية تثبت SHA السابق للبنود التي بقيت كما هي. سجل التقدم زمني منفصل.

## اختبارات المرحلة

- `pnpm check`: ناجح، بلا أخطاء TypeScript.
- `pnpm test`: 96 اختبارًا ناجحًا؛ اختبار المصادقة القديم الواحد ما زال متخطى، ومؤجل لمرحلة الهوية. لا يُقدَّم هذا العدد كإغلاق BE-11.
- `pnpm test:sync`: 40 اختبارًا إنتاجيًا على import للسكربت، بمستودعات Git مؤقتة ونقل بديل إلى bare repo محلي. تشمل الوجهات المتعددة، توسعات fetch/push والعنوان الصريح، preserve origin/hooks، تاريخ سر محذوف ورسالة commit، سباقات HEAD/worktree، تغيّر snapshot وexport-ignore، رفض skip، failure/status/retry، القفل والتعارض وSHA البعيد. لا نقل fixture إلى GitHub أو طلبات مدفوعة.
- `pnpm lint`: صفر أخطاء؛ 33 تحذيرًا موجودًا مسبقًا خارج نطاق هذه المرحلة، دون sweep للتطبيق.
- تجربة حقيقية للّقطة الأساسية قبل التغيير: تثبيت offline/frozen/ignore-scripts مستقل نجح، ثم check/test/lint نجحت. فحص اللقطة النهائي يكرره hook بعد التزام الخطوة، ولا ينسب نجاح worktree إلى SHA مختلف.

## نقطة الحفظ والتحقق الخارجي

طُلب اكتشاف عقد `manus-tools.webdev_save_checkpoint` ثم طلب تعريفه الكامل؛ أعاد الخادم **Tool not found**، والقائمة لا تعرض أي أداة webdev. لا تسجيل دخول أو إجراء حساب من العامل، ولا ادعاء checkpoint Manus زائف. يسمح التفويض بحفظ الالتزام؛ سيتم حفظ الخطوة المتماسكة بــGit مع hook المفعّل وفحوص snapshot، والتحقق من SHA `main` في الوجهة الوحيدة. **يلزم المنسق استدعاء checkpoint Manus عندما تكون الأداة متاحة لديه**. رقم checkpoint غير متاح في هذه المرحلة، ولا يجري التظاهر بأن SHA Git رقم checkpoint.

هذا التقرير مكتوب قبل الالتزام النهائي؛ SHA المحفوظ ونتيجة التحقق البعيد يبلّغ بهما الناتج المنظم للمرحلة، ويمكن استخراج SHA الحامل من Git. لا تُعدّل ملفات المصدر بعد الحفظ المتحقق إلا ضمن خطوة جديدة مختبرة وموثقة.

## العقود للمرحلة التالية

`pnpm github:sync` و`github:sync:dry-run` و`github:sync:enable` و`test:sync` بقيت الأسماء نفسها. `--skip-checks` غير مدعوم. `--verify-only` فحص محلي لا release، و`--destination-only` مخصص للمثبت. قراءة حالة المزامنة من `.git/gassar-sync-status.json`؛ هذه بيانات محلية، وليست متاحة تلقائيًا لتطبيق الهاتف. لا تبنِ لوحة تطبيق على أرقام افتراضية.

قبل كل خطوة مكتملة حدّث السجل والتقدم وتقرير مرحلتك، ثم check واختبارات المجال وtest/test:sync/lint، وحفظ checkpoint، وحقق SHA البعيد. لا تنفذ وثائق الخطة ولا تغير تقارير audit. المصدر الحالي لم يبدل API تطبيقية. سجل الإضافات ADD-01..ADD-10 ثابت؛ تفاصيل بياناته schemaVersion=1 ودلالات status موثقة داخله. لا تضع بند native complete اعتمادًا على mocks.
